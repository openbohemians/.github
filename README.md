# Open Bohemians

Open Bohemians stewards useful, dependable open source software, helping
projects develop lasting maintenance and a community of contributors.

This repository contains the initiative's public profile, founding charter,
and project register.

- [Organization profile](profile/README.md)
- [Founding charter](CHARTER.md)
- [Projects and their status](PROJECTS.md)
- [Sponsorship introduction](sponsors/introduction.md) and
  [short bio](sponsors/short-bio.txt)

The stewardship initiative is taking shape around
[Oyl](https://github.com/openbohemians/oyl), formerly YAM, and its
[Crystal bindings](https://github.com/openbohemians/oyl.cr). Their preparation
status and current repository locations are recorded in the project register.

For a project's bugs, documentation, or proposed changes, use that project's
issue tracker. To discuss the initiative or propose a project for
stewardship, open an issue in this repository describing the project's
purpose, current maintainers, and maintenance needs.

## Sponsorship

[Sponsor Open Bohemians](https://github.com/sponsors/openbohemians) to support
development, bug fixes, testing, documentation, compatibility work, and releases.

The default repository Sponsor button is configured in
[`.github/FUNDING.yml`](.github/FUNDING.yml). Repositories inherit it when
they do not define their own funding file.

The sponsorship introduction and short bio above are ready for the
Sponsors dashboard's **Profile details** fields. Editing these source files
does not update the GitHub Sponsors profile automatically.

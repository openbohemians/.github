# Open Bohemians Projects

Admission to stewardship is recorded here when a project has a named
maintainer and meets the [charter's expectations](CHARTER.md). Oyl and
Jargon were the first projects admitted, on 2026-11-15, and Merkle CHAMP
followed on 2026-11-16.

## Founding project family

| Repository | Purpose | Status | Initial maintainer |
| --- | --- | --- | --- |
| [Oyl](https://github.com/openbohemians/oyl) | SIMD-accelerated YAML 1.2 parser and emitter in C11 | Maintained | Tom (@trans) |
| [Oyl for Crystal](https://github.com/openbohemians/oyl.cr) | Crystal bindings for the Oyl project family | Maintained | Tom (@trans) |
| [Oyl for Rust](https://github.com/openbohemians/oyl.rs) | Rust bindings for the Oyl project family | Maintained | Tom (@trans) |
| [Oyl for Go](https://github.com/openbohemians/oyl.go) | Go bindings for the Oyl project family | Maintained | Tom (@trans) |

Oyl, formerly named YAM, and its bindings form one project family under
Open Bohemians, maintained since 2026-11-15. Each binding bundles its own
copy of the Oyl C library. Use each repository's releases and documentation
for the versions it supports.

## Newer projects

| Repository | Purpose | Status | Initial maintainer |
| --- | --- | --- | --- |
| [Jargon](https://github.com/openbohemians/Jargon) | Command line parsing via JSON Schema, in [Crystal](https://github.com/openbohemians/jargon.cr) and [Rust](https://github.com/openbohemians/jargon.rs) | Maintained | Tom (@trans) |
| [Merkle CHAMP](https://github.com/openbohemians/merkle-champ) | Persistent CHAMP hash map and set in Rust, with canonical shape, cached Merkle identities, and structural diff | Maintained | Tom (@trans) |
| [C0DATA](https://github.com/c0data) | Structured data using ASCII C0 control codes: a specification and seven implementations | Preparing for stewardship | Tom (@trans) |

Jargon, the specification and its Crystal and Rust implementations, has
been maintained since 2026-11-15, and Merkle CHAMP since 2026-11-16.
C0DATA joined on 2026-11-08 and keeps its repositories in its own GitHub
organization, [c0data](https://github.com/c0data).

## Project statuses

| Status | Meaning |
| --- | --- |
| Preparing for stewardship | A candidate is being prepared for admission; outstanding work is still being resolved. |
| Maintained | Named maintainers accept responsibility under the charter and state what they support. |
| Seeking a maintainer | Continued maintenance needs someone to take responsibility; support may be limited. |
| Retired | The project is preserved for reference and no further maintenance is planned. |

## Other projects

Open Bohemians also hosts [Memo](https://github.com/openbohemians/memo),
a Crystal library for portable semantic memory, and
[March](https://github.com/openbohemians/march). Their stewardship status
will be recorded here after review. Use each repository's own documentation
for its present maintenance and release status.

# Open Bohemians

Open Bohemians stewards useful, dependable open source software, helping
projects develop lasting maintenance and a community of contributors.

We are building a small home for projects people can rely on. Our focus is
practical: clear responsibility, well-documented releases, care for existing
users, and opportunities for contributors to become maintainers.

## Beginning with Oyl

Our founding project family is [Oyl](https://github.com/openbohemians/oyl),
the optimized YAML library: a YAML 1.2 parser and emitter written in C11
with SIMD acceleration, together with its
[Crystal bindings](https://github.com/trans/yam.cr).
Formerly named YAM, Oyl is now part of Open Bohemians. We are preparing
the project family for stewardship, including documenting supported
releases and compatibility between the library and its bindings.

The [project register](https://github.com/openbohemians/.github/blob/main/PROJECTS.md)
records project locations and stewardship status, including the other
projects hosted in the organization.

## Taking part

Bug reports, documentation, testing, and thoughtful code contributions all
help a project last. Start with the issue tracker of a project you use.

Open Bohemians is currently led by Tom
([@trans](https://github.com/trans)), with the aim of growing shared
stewardship as contributors take on responsibility.

Read our [founding charter](https://github.com/openbohemians/.github/blob/main/CHARTER.md)
or [discuss the initiative](https://github.com/openbohemians/.github/issues).
